DeepBlocker's eight schemes

Each scheme is a different way to turn a tuple's word vectors into one vector for the tuple. What comes before that step, serialising the tuple and embedding each word, and what comes after it are shared, so they are drawn once. Each scheme below is drawn in the same three columns, so they compare down the page.

Aggregation

SIF

A weighted average of pretrained word vectors. Frequent words count for little.

Self-reproduction

Autoencoder

A two-layer feed-forward encoder turns the SIF vector v into a hidden vector u, and a matching decoder rebuilds v from it. The hidden vector is the embedding.

Seq2seq

An LSTM encoder reads the word vectors in order and an LSTM decoder has to predict the words back, each from the one before. Word order counts, which averaging throws away.

Trans-encoder

The same idea as Seq2seq with a standard transformer in place of the LSTMs: every token attends to every other at once, rather than one after another.

Cross-tuple training

CTT

Cross-tuple training: each tuple is averaged by SIF and passed through a Siamese two-layer feed-forward summarizer whose twins share one set of weights, and a two-layer feed-forward classifier learns to spot a match from the absolute difference between them.

CTT-cosine

The same Siamese network as CTT with cosine similarity in place of the classifier, the same score vector pairing uses.

Triplet loss minimization

SBERT

Pretrained BERT with Sentence-BERT aggregation, trained with a triplet loss on generated triplets.

Hybrid

Hybrid

Autoencoder and CTT stacked: the Autoencoder is trained first, then its encoder, left frozen, replaces SIF as the aggregator of a CTT model whose summarizer and classifier are trained on pairs.

Token splits, weights and vector values are illustrative.
