One Record, One Row

A profile does not fan out. Each source record opens its own generator from the run's seed and its own id, draws one scenario from those that apply to it, runs that scenario's chain, and always emits exactly one row, changed or not. A corpus of 817,761 records is 817,761 rows, joinable one-to-one against its source. Every value below is real output of en-robustness v1.

A row is always emitted

gb-1 at seed 42 drew light-typo, both trials at 0.4 missed, and the row was written with its name unchanged, changed false and the step in steps_that_landed_nothing. That is a different row from one no scenario applied to, which carries a null scenario_id and an empty list. Skipping either would break the one-to-one join with the source.

Chain order is the author's

suffix-then-typo substitutes the suffix first, while it is still there to recognise, and only then mistypes. Nothing enforces that order: the reverse simply finds no suffix and lands nothing, and the only signal is the step's name in steps_that_landed_nothing. At 0.3 over two attempts the typo step landed nothing on four of the six suffix-then-typo draws above, which is what the numbers predict, not a fault.

Case is folded for lookups

Every table in the package is lowercase and Ireland's register holds MAGUIRE GROUP LIMITED. The lookup folds case and the replacement carries the original's capitalisation back, so the suffix was recognised and came back upper. Before that fold, the typo step fired on 378 rows of a real 817,761-row Irish run instead of roughly 64% of them, and looked like a quiet operator rather than a broken one.

What the rules hold, the output holds

legal_suffix.variant_substitution picks any spelling the country's rules record for the matched suffix's own canonical form, so a GB Limited can come back as the Welsh Cyf or Cyfyngedig, and some entries carry no spaces, as in Publiclimitedcompany. The operator reproduces the rules data as it stands; whether every such spelling belongs in a robustness corpus is a question for the rules, not the runner.
