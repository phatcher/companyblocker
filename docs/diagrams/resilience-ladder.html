Resilience Ladder

Blocking runs independently at three data-quality tiers, not once at the end of a pipeline: clean base names, known real aliases, and synthetic perturbations of either. Comparing precision and recall across those tiers, per algorithm and per noise family, is a resilience profile — a curve, not one number.

Why one hop, not a flattened path

Each layer records a pointer to only its own immediate input, never a flattened path to the ultimate primary — a perturbed row's source_uri names the variant it came from; the variant's source_uri names the primary. Flattening at write time would mean every new derived layer reaching back into an upstream artifact's own canonical schema to resolve that root; keeping each hop local avoids that entirely.
