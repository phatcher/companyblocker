From a company name to a cluster

One source name, Acme Systems P.L.C., followed through a blocking run: first the default run, the reference every other strategy is measured against, then the tokenizer and dense variants, one under the other for comparison.

The default run: TF-IDF on character n-grams

The name as it arrived, cut into character n-grams, turned into a vector, compared against the target system's names, and grouped with its matches.

Tokenizers: WordPiece and SentencePiece

The same run with a trained tokenizer in place of character n-grams. The two tokenizers split the name differently; from the vector onwards the path is the same.

Dense: sentence encoder and HNSW

The same source name through a dense run. A model turns the whole name scored into one fixed-width vector; the index is where dense search differs from sparse.
